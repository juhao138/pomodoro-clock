桌面时钟番茄钟（Windows）
=========================

全屏覆盖的桌面时钟 + 番茄钟 + 待办清单。
双击 桌面时钟番茄钟.exe 即可，单文件、无依赖、免安装（约 280 KB）。


一、界面
--------

两栏不对称布局（Google 风）：左边是时钟，右边是待办，中间大片留白。

  左栏                                          右栏
                                    待办清单            2 / 5
  16:06:06                          ─────────────────────────
                                     ☐ 写周报：整理这周的 3 个结论
  2026 年 11 月 8 日  星期日          ☑ 回复客户的邮件
                                     ☐ 复现改名失败的 bug
  ( 专注 )  24:55                    ☐ 读《重构》第 6 章
   ● ○ ○ ○                           ☑ 准备周会材料

  空格 开始 · R 重置 · N 跳过 · L 待办 · E 编辑 · T 透明度 · F11 窗口 · Esc 退出

时钟贴左边距（屏宽 7.2%），超大字号，是绝对主角。

左上角有一根跟随阶段变色的竖向强调条（专注=番茄红，休息=薄荷绿/蓝），
它和时钟、日期共用同一条左轴。

时钟按排版框左边缘排版，数字字身自带留白，所以笔画会比强调条略微靠右一点——
这是刻意保留的，视觉上更松弛；强调条、日期、番茄环则严格贴住 7.2% 的左边距。

待办是一张毛玻璃卡片：圆角、白色竖向渐变填充（12% → 4%）、1px 白色描边、
顶部一条更亮的细高光、底下有一层淡投影。栏内文字左对齐、栏本身贴右边距；
标题右边有完成计数和一条细分割线。
待办内容默认不常驻：每 30 秒淡入一次、显示 8 秒，期间只有标题和计数一直可见。
按 L 可以让清单常驻，再按 L 收起。

二、番茄钟
----------

  专注 25 → 短休 5 → 专注 25 → 短休 5 → 专注 25 → 短休 5 → 专注 25 → 长休 15

每 4 个专注一次长休；阶段结束自动进入下一阶段（不想继续就按空格暂停）。

时间到会响一声柔和的风铃音：E5 → G5 → C6 三个音的上行琶音，带二次三次
泛音和指数衰减，1.75 秒，直接在程序里合成（不依赖任何音频文件、不怕文件丢失）。
音量压在峰值 26%，听得到但不吓人。想先试听：

    桌面时钟番茄钟.exe --test-chime

不想听就加 --mute。


三、待办清单
------------

轮播卡片 / 常驻卡片里可以做：
  · ↑ ↓ 选择条目（会自动切到常驻显示）
  · 鼠标点某一行 = 切换完成
  · 完成的条目会变灰加删除线，勾选框变绿

编辑在独立窗口里（按 E 打开，可以随时关掉，主画面不受影响）。
窗口和主画面是同一套视觉：暗色标题栏、扁平圆角按钮、细边框输入框、
自绘细滚动条、空输入框有灰色占位提示。

  输入框 + 「添加」    回车即可添加，支持中文输入法
  「保存」             选中条目后点它，输入框会变成编辑模式
  「切换完成」         把选中项在完成/未完成之间切换
  「删除」             删掉选中项
  双击列表项           也能切换完成
  Esc / 关闭按钮       收起编辑窗口

清单自动保存，下次启动自动读回。文件位置：优先 exe 同目录的 todo.txt
（便携），如果那里不可写就退到 %APPDATA%\PomodoroClock\todo.txt。
可以用 --todo-file 指定别的位置。


四、按键
--------

  空格      开始 / 暂停（点进度环也行）
  R / F4    重置回专注 25:00
  N / F5    跳过当前阶段
  L / F3    待办清单 常驻 / 收起
  E / F2    打开待办编辑窗口
  ↑ ↓       选择待办条目
  T / F6    透明度：100% → 91% → 78% → 66% → 100%
  F11       全屏 ↔ 980×640 窗口
  Esc       退出

中文输入法下按字母键（E / R / N / L / T）会被输入法当成拼音输入，
弹候选框、按键传不到程序。所以主窗口已经禁用了输入法关联，
字母键照常可用；万一你的输入法还是抢先，就用 F2–F6 这套等价键位。
编辑待办时输入法正常工作，拼音、候选框都正常。


五、命令行参数
--------------

  --work 50 --short 10 --long 30    自定义时长（分钟）
  --list-every 30                   每隔多少秒浮出清单（0 = 不自动浮出）
  --list-dur 8                      每次浮出多少秒
  --todo-file D:\list.txt           指定清单文件
  --window                          以窗口模式启动
  --mute                            不响提示音
  --opacity 2                       启动时用第 2 档透明度
  --selftest                        不开窗口，跑 26 项自测
  --help                            参数说明


六、自己编译
------------

  zig cc -O2 -std=c11 -Wl,--subsystem,windows -Wl,-e,mainCRTStartup ^
      -o 桌面时钟番茄钟.exe pomodoro_clock.c _build\clock.res ^
      -lgdiplus -lgdi32 -luser32 -lole32 -lcomctl32

图标（_build\clock.res）由两个脚本生成：
  python _build\make_clock_icon.py                  # 画 clock.ico（7 种尺寸）
  python _build\make_res.py _build\clock.ico _build\clock.res


七、实现要点（给自己看的）
--------------------------

  · GDI+ 抗锯齿：SmoothingModeAntiAlias；文字用 TextRenderingHintAntiAlias
    （灰度抗锯齿）。ClearType 在大字号暗底上会有彩色毛边，所以不用。
  · 双缓冲：先画到 32 位 DIB Section，再 BitBlt，全屏 10fps 不闪。
  · 字重：Segoe UI Semibold（缺失时退回 微软雅黑 UI + 加粗）。
  · 全屏：WS_POPUP + TOPMOST，矩形取 rcMonitor（盖住任务栏）。
  · 透明度：WS_EX_LAYERED + SetLayeredWindowAttributes。
  · GUI 子系统链接（双击无黑窗口），但用 AttachConsole(ATTACH_PARENT_PROCESS)
    把 --selftest 的输出接回终端。
  · 计时：WM_TIMER 100ms 触发，用 GetTickCount64 算真实 dt，不随定时器抖动漂移；
    一次 tick 跨过阶段终点时，多余秒数结转到下一阶段，不丢时间。
  · 清单轮播：g_list_clock 累加，fmod 到周期内判断是否该显示，
    alpha 每帧按 0.45 秒的速率趋近目标值，实现淡入淡出。
  · 清单存盘：UTF-8，每行 "0\t文本" 或 "1\t文本"；目录可写性用临时文件探测。


八、已知限制
------------

  · 只覆盖主显示器
  · 全屏不阻止系统休眠
  · 编辑窗口里的列表仍是系统 LISTBOX（条目由程序自绘），只有滚动条是自绘的
  · 清单上限 128 条，单条 160 字
